# JobCopilot Pro - Automated Multi-Platform Job Application Suite 🚀

An intelligent, multi-platform career automation suite tailored for **Bala Gurunadham Pamba** (Senior Flutter / Lead Mobile Engineer, 3+ Years Experience).

JobCopilot Pro continuously tracks and aggregates high-fit Flutter engineering openings across **LinkedIn, Naukri, Indeed, Instahyre, RemoteOK, and Wellfound**, with integrated **Human-in-the-Loop Permission Gates**, automated cover letter generation, and built-in ATS-optimized resume distribution.

---

## 🌟 Key Features

- **Multi-Platform Job & Recruiter Post Aggregator**: Real-time scraping and matching across 6 major job boards and recruiter hiring posts.
- **ATS Match Scoring Algorithm**: Scans role requirements against commercial Flutter expertise (POS Hardware, MQTT, Offline-First SQLite/Isar, Payment Gateways, Background GPS, State Management).
- **Strict Permission Gates**: Every application preview requires explicit user confirmation before recording or submission.
- **ATS-Optimized PDF Resume Hub**: Direct inline preview and instant download of Bala's tailored PDF resume.
- **24/7 Cloud Ready**: Native Render.com and cloud-native architecture with zero local laptop dependencies.
- **Mobile Responsive Design**: Clean dark-mode UI with real-time radar polling and push toast alerts.

## 🛠️ Tech Stack

- **Backend**: Node.js, Express.js, Cheerio, CORS
- **Frontend**: Vanilla HTML5, CSS3 Glassmorphism, Modern Async JavaScript
- **Deployment**: Render.com (`render.yaml`, `Procfile`), Cloudflare HTTP/2 Edge

---

## 🚀 Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the local server:
   ```bash
   npm start
   ```
   Open `http://localhost:3500` in your browser.

3. To share across devices globally via secure tunnel:
   ```bash
   npm run share
   ```

---

## 🌐 24/7 Cloud Deployment (Render.com)

This repository includes [`render.yaml`](./render.yaml) and [`Procfile`](./Procfile) for zero-config deployment:

1. Sign in to [Render.com](https://render.com) using GitHub.
2. Click **New +** ➔ **Web Service** ➔ Select `Balu-142/job-copilot`.
3. Click **Deploy Web Service**.
4. Render builds and hosts the app on a permanent HTTPS domain available 24/7 worldwide.
